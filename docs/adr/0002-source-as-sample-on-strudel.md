# Built on Strudel; the Source Track is used as a sample

PUNCHISEUR is built on Strudel (a Web Audio pattern language). The Source Track — the song you punch up — is loaded as a Strudel sample and built *around*; its recorded performance is never re-synthesised or transcribed to notes. "Punch" is additive-led: we stack genre Layers (synths, drums) on top and apply light processing to the original, rather than reconstructing the music symbolically.

## Considered and rejected

- **Audio → symbolic transcription** (stem-split + note transcription, then re-pattern everything): far more powerful, but transcription errors compound and it's fragile — not worth it for an energy-layering goal.
- **DAW-style audio DSP as the core:** Strudel isn't built for that, and additive layering delivers the "punch" with far less engine.
